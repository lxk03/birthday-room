# 生日小屋 🎂

一间**俯视**的小屋：从斜上方看进去，地板、两面墙、书架上摆着书，窗边趴着一只猫。

**十件家具里各藏着一句话。** 点齐十件，蜡烛会自己亮起来；许个愿，然后吹灭它。

---

## 本地怎么看

双击 `index.html` 就能打开。

如果声音或进度没反应，用本地服务器打开更稳（在 `birthday-room` 文件夹里执行）：

```
python -m http.server 8765
```

然后浏览器打开 <http://127.0.0.1:8765>

## 怎么改

**只有 `config.js` 需要动。** 用记事本打开它：

| 改什么 | 改哪 |
|---|---|
| 寿星名字 | `who` |
| 日期 | `dateText`、`year` |
| 家具里的话 | `notes` 里的十条 |
| 门的彩蛋 | `doorNote` |
| **音乐** | 把 mp3 放进 `music/`，在 `tracks` 里列出来 |
| **照片** | 把图片放进 `photos/`，在 `photos` 里列出来 |
| 集齐之后的那段 | `finale` |
| 底部署名 | `signature`（留空就不显示） |

改完保存，刷新页面就生效。

### 音乐

1. 把 mp3 丢进 `music/` 文件夹
2. 在 `config.js` 里写：

```js
tracks: [
  { title: "窗边留座", src: "music/1.mp3" },
  { title: "夜里十点", src: "music/2.mp3" }
],
```

点唱片机会**按顺序切下一首**，一首放完自动接下一首。
不写 `tracks`，就自动用程序合成的八音盒版生日歌。

### 照片（点墙上的胶卷）

1. 把照片丢进 `photos/` 文件夹
2. 在 `config.js` 里写：

```js
photos: [
  "photos/1.jpg",
  "photos/2.jpg",
  "photos/3.jpg"
],
```

点左墙上那卷胶片，会弹出一条胶片样式的轮播，3.4 秒自动翻页，也能左右手动切。

> 建议照片先压到 1600px 宽以内，不然手机上加载会慢。

### 文案建议

- 每句话 **20~45 字**最好看，太长了纸条会换行
- 用**具体的细节**比用形容词动人得多
- 十句里留一两句轻松的，别全是抒情

## 发到 GitHub Pages（朋友能点开链接）

不需要装 git，也不需要命令行，网页上拖几下就行。

### 1. 建仓库

1. 登录 [github.com](https://github.com)，右上角 **+** → **New repository**
2. Repository name 填 `birthday-room`
3. 选 **Public**（免费账号的 Pages 只支持公开仓库）
4. 点 **Create repository**

### 2. 传文件

1. 新仓库页面上点 **uploading an existing file**
2. 把 `index.html`、`style.css`、`main.js`、`iso-room.js`、`config.js` 五个文件拖进去
3. 底下点 **Commit changes**

### 3. 打开 Pages

1. 仓库顶部 **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选 `main`，目录选 `/ (root)`
4. 点 **Save**

等 1~2 分钟，页面顶部会出现你的链接：

```
https://你的用户名.github.io/birthday-room/
```

直接发微信 / QQ / 短信，点开就能进。手机上也能玩。

### 4. 以后要改

在 GitHub 仓库里点开 `config.js` → 右上角铅笔图标 → 改 → **Commit changes**。
等一分钟刷新，链接不变。

## 关于隐私

免费 GitHub 账号的 Pages 只支持 **Public 仓库**，所以源码和里面的文字是公开的。
这里放的是祝福文字，一般没问题。

如果之后想放**真人照片**或不想公开，两个办法：

- 照片先做卡通化 / 只放你们俩知道的局部
- 换 [Vercel](https://vercel.com) 或 Netlify 部署（同样免费，支持私有仓库）
